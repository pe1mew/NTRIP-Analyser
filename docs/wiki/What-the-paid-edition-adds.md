# What the paid edition adds

The two editions **measure identically**. The eight checks, their
thresholds and their verdicts come from one engine, so a station that
passes in one passes in the other. Nothing is measured differently, and
nothing is held back to make the free edition look worse.

What the paid edition buys is *more work done for you*, and one thing
the free edition deliberately does not do at all.

| | Free | Pro |
|---|---|---|
| The eight checks, the verdict, the analysis views | yes | yes |
| Saved connections | one | several, switched from the main screen |
| Choosing a mountpoint from the sourcetable | read the list, type the name | tap it, and its position and settings come with it |
| Watch mode — keep measuring for hours, with availability and degradation counts | — | yes |
| Ephemeris side-stream for a complete sky view | — | yes |
| Import and export of the shared configuration file | — | yes |
| Position sent to a network mountpoint | the one you set | this phone's own, after an explicit agreement |
| Per-message-type statistics and the full ARP detail | — | yes |

## The one real difference in behaviour

**The free edition never sends your position anywhere.** For a network
mountpoint it sends the position *you* set — typed, picked on a map, or
taken from the station's own sourcetable entry.

The paid edition can report where the phone actually is, so a network
service answers for where you are standing. It asks once, explicitly,
naming the caster it will be sent to, and you can turn it off again.
That difference is the reason the two editions declare different things
on the Play data-safety form.

## Why watch mode is not in free

A spot check grades a station; a watch observes one. Sixty seconds
answers *is it healthy now*, and hours answer *does it stay healthy* —
which is the question an operator is paid to answer, and the one that
costs real time to run.

Buying it is buying the tool's time, not access to a number that was
being hidden.
